# Task Management App

## Overview

The Task Management App is a JavaScript application that allows users to create, organize, update, and filter their tasks.

## Features

* Add tasks with a task name, category, deadline, and status.
* Store tasks as JavaScript objects inside an array.
* Display tasks dynamically using DOM manipulation.
* Update task status between In Progress, Completed, and Overdue.
* Automatically mark unfinished tasks as Overdue when their deadline has passed.
* Filter tasks by status and category.
* Save task data with localStorage so tasks remain after refreshing the page.
* Responsive layout for smaller screens.
* User feedback when tasks are added or updated.

## Files

* `index.html` – Application structure.
* `style.css` – Application styling.
* `app.js` – JavaScript functionality.
* `Reflection.md` – The project reflection.

## How to Use

Enter a task name, select a category, choose a deadline and status, and click **Add Task**. Use the status dropdown on each task to update its progress. The filter controls can be used to display tasks by category or status. Tasks are automatically saved in the browser using localStorage.
