# Reflection

One of the main challenges I faced during this project was connecting several JavaScript concepts together in one application. I had to use arrays and objects to store task information while also using DOM manipulation to display and update the tasks on the page. Adding automatic overdue checking and filtering required me to think carefully about conditionals and how each task should be handled.

I approached these challenges by building the application in smaller steps. I first created the basic layout, then added task creation, dynamic display, status updates, overdue checking, filtering, and then localStorage. Testing each feature separately helped me find problems before moving forward.

If I had more time, I would add features such as deleting tasks, editing task information, and adding additional categories. Overall, this project helped me better understand how JavaScript can make a webpage interactive.
